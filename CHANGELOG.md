# Changelog

## 0.1.0

- Independent Linux/WSL2 distribution with prefix installation and guarded uninstall.
- Codex/Claude CLI dashboard with 60/40 layout, quota, optional GPU and task logs.
- Current-slot instructions injected into new and resumed agent sessions.
- User-owned XDG state, isolated tmux service, concurrent slot reservation.
- Normal CLI authentication and permissions preserved; explicit unsafe opt-in.
- CPU-only fallback, dependency doctor, source packaging and isolated integration tests.
